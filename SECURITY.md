# Security Policy

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue, please report it responsibly.

### Contact

- **Email**: <ipproyectossoluciones@gmail.com>
- **GitHub Security Advisories**: <https://github.com/ipproyectosysoluciones/termux-dotfiles/security/advisories>

### Response SLA

We aim to acknowledge security reports within 48 hours. Please do not open public issues for security vulnerabilities.

### Guidelines

- Please provide detailed information about the vulnerability to help us reproduce and verify the issue.
- Allow us time to address the vulnerability before disclosing it publicly.
- Do not attempt to access, modify, or delete data that does not belong to you.
